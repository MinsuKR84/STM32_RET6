Universal Asynchronous Receiver / Transmitter
클럭 신호 없이 데이터를 직렬로 전송하는 통신 방식

송신 장치와 수신 장치는 미리 동일한 통신 속도와 데이터 형식을 설정해야 함

예를 들어 다음과 같이 설정함
Baud Rate : 115200 bps
Data Bits : 8 bit
Parity : None
Stop Bits : 1 bit



UART 통신에는 기본적으로 두 개의 신호선이 사용됨
STM TX --- 상대 장치 RX 
STM RX --- 상대 장치 TX
STM GND --- 상대 장치 GND

TX는 데이터를 송신하고 선이고, RX는 데이터를 수신하는 선임
TX와 RX를 서로 교차 연결해야 함
UART는 TX와 RX가 분리되어 있으므로 동시에 송신과 수신이 가능한 전이중 통신임




UART에는 클록 선이 없음
따라서 송수신 장치는 동일한 Baud Rate를 사용하여 각 비트의 위치를 판단함

예를 들어 9600 bps로 설정하면 한 비트의 전송 시간은 1/9600 = 104.17us임
송신 장치와 수신 장치의 Baud Rate 오차가 너무 크면 비트 위치를 잘못 인식하여 데이터가 깨질 수 있음



UART는 데이터를 다음과 같은 프레임으로 전송함

Start | D0 D1 D2 D3 D4 D5 D6 D7 | Parity | Stop

Start Bit : 통신 시작을 알리는 비트임, UART 선은 평상시에 High 상태이고, 전송이 시작되면 Low로 내려감

Data Bits : 실제로 전송되는 데이터임.
UART는 보통 최하위 비트인 LSB부터 전송함

예를 들어 0x41은 0100 0001임, 전송 순서는 LSB부터이므로
1 → 0 → 0 → 0 → 0 → 0 → 1 → 0

Parity Bit : 전송 과정에서 단순한 비트 오류를 확인하기 위한 비트임

대표적인 방식 3가지
Even parity : 전체 1의 개수를 짝수로 맞춤
Odd parity : 전체 1의 개수를 홀수로 맞춤
None : 패리티를 사용하지 않음
패리티는 제한적인 오류 검출만 가능하며, 오류를 수정하지는 못함

Stop Bit : 한 프레임의 종료를 나타냄, 일반적으로 1비트를 사용함



UART 통신 과정
STM32가 문자 A를 송신한다고 가정
1 STM32가 문자 A의 ASCII 값 0x41을 UART 데이터 레지스터에 기록함
2 UART 주변장치가 Start Bit를 출력함
3 0x41의 데이터 비트를 한 비트씩 전송함
4 설정에 따라 Parity Bit를 전송함
5 Stop Bit를 출력함
6 상대 장치는 동일한 Baud Rate를 기준으로 데이터를 복원함



UART 장단점
장점
회로와 코드가 단순함
TX, RX 두 신호선만 필요함
PC 시리얼 모니터를 통한 디버깅에 적합함
송신과 수신을 동시에 수행할 수 있음

단점
기본적으로 1:1 통신에 적합함
클럭 오차에 영향을 받음
장거리 및 노이즈 환경에 상대적으로 약함
장치 주소가 기본적으로 존재하지 않음
