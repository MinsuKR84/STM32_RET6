
# 4개 로드셀 연결 방식

로드셀을 4개 모서리에 배치했다고 가정하겠습니다.

상부에서 본 바닥판

앞쪽
┌─────────────────┐
│  L1                                      L2  │
│                                                │
│  L3                                      L4  │
└─────────────────┘
뒤쪽


L1 = 앞왼쪽
L2 = 앞오른쪽
L3 = 뒤왼쪽
L4 = 뒤오른쪽

## 기본 연결 추천

### E+ 연결

4개 로드셀의 **빨강선 전부**를 묶어서 HX711의 **E+**에 연결합니다.

```
L1 빨강 ┐L2 빨강 ├── HX711 E+L3 빨강 ┤L4 빨강 ┘
```

---

### E- 연결

4개 로드셀의 **검정선 전부**를 묶어서 HX711의 **E-**에 연결합니다.

```
L1 검정 ┐L2 검정 ├── HX711 E-L3 검정 ┤L4 검정 ┘
```

---

### A+ / A- 연결

노랑선은 전부 한곳에 묶지 말고 **대각선끼리 나눕니다.**

```
L1 노랑 + L4 노랑 → HX711 A+L2 노랑 + L3 노랑 → HX711 A-
```

정리하면:

|로드셀|빨강|검정|노랑|
|---|---|---|---|
|L1 앞왼쪽|E+|E-|A+|
|L2 앞오른쪽|E+|E-|A-|
|L3 뒤왼쪽|E+|E-|A-|
|L4 뒤오른쪽|E+|E-|A+|

모식도는 이렇게입니다.

┌─────────┐
│  L1(A+)       L2(A-)│
│                         │
│  L3(A-)       L4(A+)│
└─────────┘
